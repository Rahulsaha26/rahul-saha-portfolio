# Rahul Saha — Free Portfolio Website

## Quick start
1. Open `index.html` in a browser to preview the site.
2. Replace `YOUR_EMAIL@example.com` in `index.html` with your email.
3. Put your CV at `assets/Rahul_Saha_CV.pdf`.
4. Put map images in `assets/maps/` and add gallery cards to `index.html`.

## Publish FREE with GitHub Pages
1. Create/sign in to GitHub.
2. Create a new public repository, e.g. `rahul-saha-portfolio`.
3. Upload all files from this folder.
4. In the repository: Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
5. GitHub will give you a free `github.io` website address.

The website is plain HTML/CSS/JS, so no paid hosting or database is required.
